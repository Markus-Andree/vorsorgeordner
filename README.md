# Digitaler Vorsorgeordner

Eine kostenlose App, die alle wichtigen Angaben für den Ernstfall an einem Ort sammelt – damit Angehörige sofort wissen, was zu tun ist.

**App öffnen:** https://markus-andree.github.io/vorsorgeordner/

## Was die App kann

- Fragen in einfacher Sprache, eine nach der anderen – mit **Vorlesen** und **Antworten per Sprache**
- Checkliste **„Im Ernstfall“** mit den wichtigsten Schritten und Fristen
- **Notfallblatt** zum Ausdrucken für die Angehörigen
- Auf dem Handy installierbar, funktioniert auch ohne Internet

## Datenschutz

- Alle Angaben werden **nur auf dem eigenen Gerät** gespeichert, verschlüsselt mit AES-256 (Schlüssel aus dem Passwort per PBKDF2, 600.000 Durchläufe).
- Es werden **keine Daten** an einen Server geschickt. Diese Seite liefert nur das leere Programm aus.
- Ausnahme: Beim Sprechen von Antworten nutzt der Browser seinen eigenen Sprachdienst (Google, Microsoft oder Apple).

Die Hinweise in der App sind allgemeine Informationen ohne Gewähr und keine Rechts- oder Steuerberatung.
